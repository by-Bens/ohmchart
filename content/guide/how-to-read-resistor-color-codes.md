title: "How to Read Resistor Color Codes"
description: "A step-by-step guide to reading 4-band resistor color codes, with the full digit, multiplier, and tolerance chart."
---

Resistors are too small to print numbers on legibly, so manufacturers use
colored bands instead — a standard called IEC 60062. Once you know the
pattern, reading one takes a few seconds.

## Step 1: Find the tolerance band

It's usually gold or silver, set slightly apart at one end. Read _from_
that end, but read the tolerance band _last_.

## Step 2: Read the digit bands

| Color  | Digit |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Grey   | 8     |
| White  | 9     |

## Step 3: Apply the multiplier

The next band tells you how many zeros to add.

## Worked example

Bands **Red, Red, Brown, Gold**: Red, Red → "22". Brown → ×10.
22 × 10 = **220 Ω**. Gold → ±5% tolerance.
